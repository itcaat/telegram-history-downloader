# Инструкции для агента

## Проверка перед сдачей изменений

Перед тем как отдавать изменения пользователю, обязательно собери проект:

```bash
npm run build
```

- Команда проверяет типы (`tsc --noEmit`) и собирает расширение в `dist/`.
- Изменения можно отдавать только после успешной сборки без ошибок.
- Если сборка упала, исправь ошибки и запусти её снова.
- В ответе пользователю укажи, что сборка прошла успешно. Если что-то проверить не удалось (например, работу в живом Telegram), так и напиши.
